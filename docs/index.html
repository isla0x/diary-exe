하루에 한 줄이면 충분해. 입력창에 한 줄 치면 끝나는 CMD 스타일 일기 앱이에요. 1년 뒤 오늘, 오늘 쓴 한 줄이 돌아와요.

명령어

명령어설명
echo 퇴근길 노을오늘 한 줄 저장 (80자까지). 명령어 없이 입력해도 저장돼요.
edit 고친 내용
edit 09.28 내용		오늘 한 줄 고치기. 날짜를 붙이면 지난 날도 쓰거나 고칠 수 있어요.
rm / rm 09.28그날 한 줄 지우기
cat 어제, cat --ago그날 한 줄 보기 / 지난해 오늘들
grep 커피모든 기록에서 단어 찾기
ago / cal해마다 같은 날 모아 보기 / 달력과 연속 기록
mode light밝기 모드 auto · light · dark. auto 는 폰 설정을 따라가요.
theme amber, crt on테마 · CRT 효과 (PRO)
upgrade / restorePRO 구매 / 구매 복원

자주 묻는 질문

하루에 여러 줄 쓸 수는 없나요?

diary.exe 는 하루 한 줄만 남기는 앱이에요. 부담 없이 오래 쓰도록 일부러 한 줄로 제한했어요. 대신 edit 로 언제든 고쳐 쓸 수 있어요.

어제 쓰는 걸 깜빡했어요

edit 어제 내용 이나 edit 09.28 내용 처럼 날짜를 붙이면 지난 날에도 쓸 수 있어요.

위젯에 "Access is denied." 가 떠요

홈 화면·잠금화면 위젯은 PRO 기능이에요. 앱에서 upgrade 를 입력해 PRO 를 열면 위젯이 바로 풀려요.

폰을 바꿨는데 PRO 가 사라졌어요

같은 Apple ID(또는 Google 계정)로 로그인한 뒤 앱에서 restore 를 입력하면 구매가 복원돼요.

일기를 다른 기기로 옮길 수 있나요?

아직은 안 돼요. 모든 일기는 기기 안에만 저장돼요. 내보내기는 다음 업데이트에서 준비 중이에요.
